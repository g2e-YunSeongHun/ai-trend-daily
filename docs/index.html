같은 Haiku 5.5, 에이전트 따라 MCP 활용률 17점 차이 — 3,717회 벤치마크

21개 MCP 서버·3,717회 실행으로 Claude Code 2.1.312·OpenCode 1.19.5(둘 다 Claude Haiku 5.5)·Codex 0.165.0(GPT-6 Luna)의 MCP 도구 활용을 비교한 벤치마크.

모델이 같아도 OpenCode 82.0% vs Claude Code 65.4%로 벌어졌고, 차이는 대부분 내장 도구와 겹치는 서버(웹 검색·문서·파일)에서 에이전트가 MCP 대신 자체 도구를 쓴 데서 나왔다(MCP 무시율 Codex 44.5%, Claude Code 36.5%, OpenCode 16.1%). 내장 도구와 겹치지 않는 Postgres·Redis·K8s 류 서버는 세 에이전트가 4.1점 이내였다. MCP 서버를 붙일 때 내장 도구와의 중복부터 따져보라는 시사점이 있고, 측정 도구 M3와 방법론이 공개돼 있다.

crewAI 1.15.34 — skill search·run --inputs·deploy --zip 추가

멀티에이전트 프레임워크 crewAI의 CLI에 조직 스킬 검색, Python 플로우로의 입력 전달, zip 배포 명령이 추가된 릴리스.

crewai skill search로 조직에 등록된 스킬을 CLI에서 바로 찾을 수 있고, crewai run --inputs가 Python 플로우까지 전달된다. 1.15.29의 에이전트 실행기 제거가 Breaking Change로 명시돼 있어 업그레이드 전에 마이그레이션 노트를 봐야 한다. 그 외 빈 LLM 응답 1회 재시도, context_window_size 준수, LiteLLM 도구호출·구조화출력 토큰 집계 등 버그 수정이 많다.

stack-diagram — 공식 로고가 들어간 아키텍처 다이어그램을 그리는 Agent Skill

surgical-context-mcp — 파일 전체 대신 편집 컨텍스트만 주는 MCP 서버

Tree-sitter로 코드 그래프를 만들어 함수 본문·파일 스켈레톤·호출자·헬퍼만 에이전트에 주는 로컬(SQLite) MCP 서버.

README 예시 기준 1,264줄 파일을 편집할 때 13.3k → 3.7k 토큰으로 줄어든다. 큰 파일 읽기를 막는 훅 설치 명령과 리팩터 안전성 검사 도구가 포함되고, Claude Code·Cursor·Windsurf·Cline·Claude Desktop을 지원한다. PyPI와 공식 MCP 레지스트리에 등재돼 있지만 공개 직후라 검증 사례는 아직 적다.

AI Media Router — 43개 공급자의 이미지·영상 생성을 묶는 MCP 서버

Seedance·Kling·Veo·Wan·FLUX·GPT Image 등을 fal·Replicate·kie·Runware·OpenRouter 등 43개 공급자로 생성하는 오픈소스(MIT) MCP 서버.

session-lens — Claude Code 토큰·서브에이전트 사용을 보여주는 관측 플러그인

llx-desk — 에이전트가 조작하고 사람이 지켜보는 브라우저·터미널 창

Claude Code·Codex 등이 셸에서 호출해 브라우저 탭(WKWebView/WebKitGTK)과 PTY 터미널 탭을 여는 Rust 네이티브 창.
